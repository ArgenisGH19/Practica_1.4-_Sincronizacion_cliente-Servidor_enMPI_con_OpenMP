# Practica_1.4-_Sincronizacion_cliente-Servidor_enMPI_con_OpenMP
Implementar el modelo Cliente-Servidor utilizando MPI para coordinar el acceso concurrente y controlado a un recurso compartido (saldo bancario) centralizado en el proceso maestro (nodo 0), sin utilizar hilos centralizados ni mecanismos de sincronización externos como candados distribuidos o memoria compartida física.
